# 2026-10-29 优化与验证记录

> 本页记录当天较早的UI与诊断层优化阶段。后续已新增完整 Agent 工作流和真实LLM接入，其当前能力与真实验证记录见[Agent演示与验证指南](agent-demo.md)。本页的“未调用真实LLM”等陈述仅适用于当时这轮验证。

本轮保留原有 FastAPI、LangGraph、模拟器与本地数据库，完成诊断逻辑、流程状态及工作台界面优化。项目仍是模拟演示，不连接真实设备。

## 完成的改动

- 工作台拆分为 HTML、CSS、JavaScript，无前端构建步骤或外部 CDN 依赖。提供总览、证据诊断、知识库、会话报告四个视图，支持手机抽屉导航。
- 总览增加压力/流量/完整率/模拟时长指标，30、90、180 分钟趋势窗口、阈值线、悬浮读数、处置标记与运行轨迹。缺失数据保留断点，孤立有效读数显示为点。
- 一键演示仅创建会话、推进模拟、生成规则诊断；模拟处置仍需独立确认。按钮按后端能力启用，显示不可用原因，防止重复提交。
- 诊断按观测区分联合异常、仅压力异常、仅流量异常、正常与数据不足，返回摘要、信号类别、候选原因和引用依据。BM25 索引复用，LLM 结构和引用校验更严格。
- 推进模拟使历史诊断过期；确认令牌校验版本和时效；处置后必须复核；曾执行处置的会话不能通过再次诊断或重启重新开放不适用的预测。
- 状态和报告查询不再全量写库，修改仅保存当前会话；慢 LLM 调用不阻塞状态读取，工况变化后拒绝旧结果。预测模型按文件版本缓存。
- 最近会话支持恢复，页面刷新保留当前会话。会话切换只有在完整读取成功后才更新，避免错误地操作另一个会话；连接失败明确显示异常。

## 验证结果

`python -m pytest -q`：51 项通过。JavaScript 语法检查通过。

通过 Playwright 在本地服务上实际验证：

- 供浆阻力演示 → 取消处置 → 重新诊断 → 模拟事件评分 → 确认清理 → 独立复核恢复 → 参数实验，生成 5 个候选，参数未自动应用。
- 正常、传感器偏差、数据缺失工况能显示对应诊断，并禁用不适用的模拟清理。
- 缺失数据图保留独立有效点；趋势时间范围与指标切换可用。
- 页面刷新恢复会话，证据列表可读，知识搜索有效，Markdown 报告实际下载成功。
- 1440px 桌面与 390px 手机布局无横向溢出；隐藏抽屉不可聚焦，手机导航可切换视图。
- 在测试浏览器注入会话读取 404，验证切换失败不会混合会话状态；注入网络断连，验证连接提示变为异常，恢复网络后可继续使用。
- 正常运行未发现浏览器脚本错误；故障注入期间的预期网络错误不计为正常运行缺陷。

截图与下载样本位于 `output/playwright/`，测试浏览器记录位于 `.playwright-cli/`；两者已加入忽略规则。原有用户会话保留，浏览器验证产生的模拟会话留在本地供查看。
