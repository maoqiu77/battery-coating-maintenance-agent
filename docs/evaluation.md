# 评测说明

所有指标只适用于本项目的模拟器和手写测试。复现：

```bash
uv run pytest -q
uv run python scripts/train.py --seed 42 --assets 120
uv run python scripts/evaluate.py
```

训练报告生成在 `artifacts/model-report.json`；知识检索与流程结果生成在 `artifacts/evaluation.json`。数据不来自真实涂布设备。运行版本与配置发生变化时，报告数值以实际重新运行的结果为准。

## 划分和标签

根据资产 ID 固定随机划分，完整资产只属于一个集合。目标是未来 1–30 分钟达到模拟阻力阈值；事件之后的窗口与未来观察不足 30 分钟的窗口不参与训练或测试。特征来自当前时点前 30 个观测，未包含隐藏阻力、故障标签、未来数据、资产 ID。各模型阈值仅通过验证集选择。

测试中的窗口高度相关，因此窗口指标不能当成独立样本的统计保证；测试报告同时给出事件级召回、首次预警提前量和正常轨迹误报比例。预测模型以同一生成规则训练和测试，且参数扰动有限；指标可能主要反映其对模拟规则的拟合。

额外输出压力传感器偏差、泵效率下降、混合故障、阻力参数偏移的触发比例。它们是域外诊断线索，未被伪装为实际工业故障的准确率。没有外部真实数据或专家标注；后续应引入独立知识审核、更多生成机制、不同故障条件与真实设备数据后再评价迁移。

一次运行（seed=42、120 个模拟资产）中，18 个传感器偏差域外案例有 9 个在第 180 分钟超过 XGBoost 的验证集阈值。这个反例表明模型可能把不同异常误判为阻力故障风险；不要根据它独立决定处置。

## 检索及流程

五个手写检索查询评估 Recall@3 与 MRR，另有一个无关问题检查零召回；语料和问题同作者、样本量极小。失败记录应查看完整 JSON，而不是仅看平均分。数据缺失案例应拒绝确定原因，处置无效案例应保持未恢复。单元测试还覆盖未来时钟、一次性确认、并发确认和会话恢复。

## LLM 评测限制

离线模板可重复运行；外部模型输出并不保证可复现。旧的诊断接口会在校验失败时回退模板；新的 Agent 规划接口会显式转人工并记录 `llm_unavailable`，不替换为规则动作。两者都要求引用来自实际取证结果。

新增 `scripts/evaluate_agent.py` 用隔离内存会话验证六种工况、动作失败和只诊断边界。规则模式八例通过；2026-10-29 首轮 `gpt-6.1-terra` Responses 真实调用满足预期5/8，混合第二轮规划校验及两个限流案例未通过完整验收。详细分项和后续验证应查看[Agent演示与验证指南](agent-demo.md)及生成的 `artifacts/agent-llm-evaluation.json`，不能用规则结果替代真实模型结果。

这些是少量固定模拟案例，没有大规模或真实产线对比，不能声称具体 LLM 诊断精度。评测夹具的自动批准始终标记为 `test_harness`，不代表产品自动获准执行。
